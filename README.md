# Meet Assistant

This repository is a learner's project that takes the ubiquitous AI meeting app and connects it to Google Workplace APIs.
The user chooses a meeting recording and the project filters and creates tasks that could be done on Google Docs, Slides, Calendar, Gmail, and miscellaneous tasks.
Clicking on one these tasks takes the user to a new application with the summary of the task already written (with permission).
This project was to explore and master my expertise in:

React
FastAPI
Google APIs
Ollama LLMs
HTML + CSS
PostgreSQL

The Ollama model I used was gemma4:e4b for its speed and accuracy despite its fewer parameters.
